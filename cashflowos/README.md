# CashFlowOS

AI-assisted receivables and order intelligence for Indian B2B SMEs.

## MVP goal

Turn a business's outstanding-invoice spreadsheet into an actionable daily collection workflow:

**Import → Analyze → Prioritize → Follow up → Track payment**

## Initial product scope

- Owner dashboard for receivables and collection opportunities
- Customer profiles and credit exposure
- Invoice and overdue tracking
- Promise-to-pay tracking
- AI-assisted collection message generation
- Risk and collection prioritization
- CSV import/export for the first pilot

## Product principle

CashFlowOS is an operating intelligence layer above existing accounting software. It does not attempt to replace accounting systems in the MVP.

## MVP status

Initial product specification and repository scaffold. Implementation will be delivered incrementally with deterministic demo data and tests before external integrations.
